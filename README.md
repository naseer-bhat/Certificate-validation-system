# Certificate Validation System

A web-based application for validating and managing certificates securely.

## Features

- Upload and store certificates
- Validate certificates using unique identifiers
- Admin dashboard for certificate management
- User-friendly interface

## Technologies Used

- Frontend: [ React]
- Backend: [ Node.js]
- Database: [ MongoDB]

## Getting Started

1. Clone the repository:
  ```bash
  git clone https://github.com/naseer-bhat/Certificate-validation-system.git
  ```
2. Install dependencies:
  ```bash
  cd Certificate-validation-system
  npm install
  ```
3. Start the development server:
  ```bash
  npm start
  ```

## Usage

- Register or log in as an admin/user.
- Upload certificates for validation.
- Search and validate certificates by ID.
